# The World Today — Wednesday 25 November 2026

One image summing up the world's news of Wednesday 25 November 2026,
as a newspaper front page. `main.py` (Python 3.13, standard library only)
copies `entry.png` from this repository to `MAKEFUN_OUTPUT_DIR`
(default `/output`) as `entry.png`, checks it is a whole PNG or JPEG of
at most 1 MiB and 1024 by 1024 pixels, and verifies the copy with sha256.

  rises to 17,500 taka a month after weeks of protests.
